# Lookout

A VS Code extension that shows every [Claude Code](https://claude.com/claude-code) session at a glance: which ones are working, which ones need you, and where each one is running.

**Status: early development.** Nothing is released yet.

## Goals

- **See what is running and where.** One live view of every session: its state (working, waiting for you, done), its project, and what it is doing.
- **Jump to the session.** One click opens the exact Claude Code tab or terminal for a session.
- **Show Claude usage.** Session and weekly limits next to the sessions that consume them.
- **Look good.** An animated, glanceable status bar and a session board that fit the editor theme.
